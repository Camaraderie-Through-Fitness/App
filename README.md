# CTF Community App

App for Camaraderie Through Fitness, a 501(c)(3) serving veterans through group fitness, peer connection, and community.

Tabs: Home (mission, impact numbers, next event, founder story, member quote, partners), Events (all CTF events with type filters, pinned event, RSVPs, add-to-calendar, past events), Community (the Fox Hole and the member directory), Support (crisis line, gym start-fee reimbursement, partners), and Give. Admin tools open from the profile menu.

Other features: sign-in, $22/year membership for the veteran directory and stories, battle buddies, weekly devotional, and email reminders.

Built as a single page (index.html) on Firebase (login and database), hosted with GitHub Pages.

Live at https://app.camaraderietf.org (DNS: CNAME `app` → camaraderie-through-fitness.github.io, set in Squarespace).
